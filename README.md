# Emily Music

Aplicativo de música para Android em beta.

Baixe a versão mais recente em [Releases](https://github.com/vitor-sh/emily-music-releases/releases/latest).
Entre com sua própria conta Google. Bibliotecas ficam separadas por conta e sincronizam entre seus aparelhos.
Downloads, arquivos de áudio locais e reprodução ficam no aparelho.

As próximas versões são avisadas no app; o Android pede confirmação para instalar.
Nunca é necessário desinstalar para atualizar.

O código correspondente do cliente, sob GPL-3.0-or-later, acompanha cada versão.
Certificados, configurações privadas e dados de usuários não são publicados.
